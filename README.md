# 🧪 Chemistry Hub & Stoichiometry Calculator

An interactive, responsive front-end web application featuring a modern periodic table database and a real-time chemical reaction stoichiometry calculator.

## ✨ Features

- **Interactive Periodic Table:** Browse all 118 periodic elements dynamically categorized by elemental groups (Noble Gases, Alkali Metals, Halogens, etc.) with custom hover previews and detail cards.
- **Real-Time Stoichiometry Engine:** Instantly balance and scale chemical reaction ratios without reloading the page.
- **Input Edge-Case Sanitization:** Robust JavaScript validation that catches non-numeric characters, strings, and empty fields (`!isNaN(Number(val))`).
- **Modern Glassmorphism Design:** Dark-themed UI styled with CSS Grid, CSS Variables, and backdrop blur effects for high visual scannability.
- **SEO Ready:** Fully indexed with semantic HTML5 structuring and meta tags for search visibility.

---

## 🛠️ Tech Stack

- **Structure:** Semantic HTML5
- **Styling:** Modular CSS3 (Flexbox, 18-Column CSS Grid, CSS Variables)
- **Logic:** Vanilla JavaScript (ES6+, DOM Manipulation, Regex Data Parsing)

# Navigate into the directory
cd Checmisty_Reference_Project
